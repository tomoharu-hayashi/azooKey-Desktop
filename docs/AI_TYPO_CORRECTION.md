# AI誤字修正機能

azooKey on macOS に追加されたAI誤字修正機能についてのドキュメントです。

## 概要

Tabキーで誤字修正候補をAIに問い合わせ、**通常の変換候補リストの3番目**に統合表示します。

## 機能

### TypoCorrection（誤字修正）

ローマ字入力中にTabキーでトリガーすると、AIが以下を考慮して日本語変換候補を提案します：

- ローマ字のタイプミスを修正
- カーソル前の文脈を考慮した適切な変換
- 文脈に続く自然な予測（助詞や続きを含む）

**トリガー**: Tabキー

**表示位置**: 通常候補の3番目から（`+ ` プレフィックス付き）

## 動作フロー

```
ローマ字入力 → Tab
→ 候補選択モードに遷移（通常候補を表示）
→ AIに誤字修正リクエスト
→ AI候補を通常候補の3番目に挿入（+ プレフィックス付き）
→ 上下キーまたは数字キーで選択して確定
```

## 候補表示例

```
1. 発表        ← 通常候補1
2. はっぴょう   ← 通常候補2
3. + 発表      ← AI誤字修正候補（+ マーク付き）
4. + 発表を
5. + 発表します
6. ハッピョウ   ← 通常候補3
```

## 技術詳細

### プロンプト

```
あなたは日本語入力アシスタントです。
ユーザーが入力したローマ字を日本語に変換し、文脈に応じた候補を提示してください。

入力形式: `{文脈}<{ローマ字}>`
- {文脈}: カーソル前の日本語テキスト（空の場合あり）
- {ローマ字}: 変換対象のローマ字入力（角括弧内）

3〜5個の候補を以下の優先順で返してください:
1. ローマ字の最もシンプルな日本語変換
2. 文脈を考慮した変換バリエーション
3. 文脈に続く自然な予測（助詞や続きを含む）
```

### 対応バックエンド

- **Foundation Models** (macOS 26.0+): Appleのオンデバイスモデル
- **OpenAI API**: GPT-4o-mini など

### ファイル構成

## 使用例

### 例1: 基本的な誤字修正

入力: `watshi` → Tab → 候補に `+ 私`、`+ わたし` が追加

### 例2: 文脈を考慮した予測

入力: `明日の会議で` `happyou` → Tab → 候補に `+ 発表`、`+ 発表を`、`+ 発表します` が追加

### 例3: 挨拶の補完

入力: `お忙しいところ` `osoreiri` → Tab → 候補に `+ 恐れ入りますが`、`+ 恐れ入ります` が追加

## 注意事項

- AI APIの利用には課金が発生する場合があります（OpenAI API使用時）
- Foundation Modelsを使用する場合はmacOS 26.0以上が必要です
- 「いい感じ変換」がOFFの場合、Tabキーは通常の動作になります
